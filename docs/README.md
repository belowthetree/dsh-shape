## 一句话版本

dsh-shape 是 DSH 插件，把「一个目录 + 一份清单 + 可选脚本」变成可以即时启停的界面扩展：形态可以有自己的视图、在 10 个会话槽位里渲染内容、注册快捷键、读写自己的 `data/` 目录，并通过 9 个能力访问宿主功能。
